# Specification changelog

The specification is a living document
([ADR 0010](../docs/adr/0010-documentation-architecture.md)): implementation-forced
changes are recorded here, alongside an ADR and the spec edit itself. It stays
"Draft v0.x" until the language stabilizes (≈ self-hosting).

ADRs [0001](../docs/adr/0001-compiler-in-typescript.md)-[0010](../docs/adr/0010-documentation-architecture.md)
were ratified together on 2026-06-12 during the initial architecture hardening
pass.

## Draft v0.1

Initial specification: compilation model, execution model, JavaScript
interactions, mutability, borrows, lifetimes, drop & RAII, expressions & control
flow, functions & closures, primitive types, strings, collections, structs,
enums, generics & traits, pattern matching, iterators, modules, async, error
handling, JavaScript export and TypeScript declaration generation, safe/unsafe
boundaries, toolchain & packaging, and the grammar appendix.
